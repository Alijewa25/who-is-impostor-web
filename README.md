# 🕵️‍♂️ Who is the Impostor? — Party Word Game

A fast, lightweight, and completely free web-based party game inspired by classic "Undercover" and "Impostor" social deduction games. Designed to be played on a **single device (pass-the-phone mode)**—perfect for game nights, road trips, and hangouts with friends!

---

## ✨ Features

- 📱 **Single-Device Play:** Only 1 phone needed for the whole group.
- ⚡ **No Installation Needed:** Runs directly in any web browser.
- 🗂️ **Multiple Categories:** Includes Food, Cities, Everyday Objects, and Movies.
- 🤫 **Secret Role Reveal:** Tap-to-reveal mechanism keeps roles hidden between passes.
- 🎨 **Clean & Dark UI:** Modern, responsive design optimized for mobile screens.

---

## 🎮 How to Play

1. **Setup:** Select the number of players (3–10) and pick a word category.
2. **Pass the Phone:** Hand the phone around the group. Each player taps to reveal their secret word.
   - **Secret Players:** See the secret word (e.g., "Pizza").
   - **The Impostor:** Sees `YOU ARE THE IMPOSTOR! 🤫` without knowing the word.
3. **Give Clues:** Going in a circle, each player gives a 1-word or 1-sentence clue related to the secret word.
4. **Discuss & Vote:** Debate who seemed suspicious or clueless, then vote out the suspected Impostor!
