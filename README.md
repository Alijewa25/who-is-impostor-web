# 🕵️‍♂️ Who is the Impostor?

A free, web-based pass-the-phone party game played on a single device. Designed for group hangouts, game nights, and social events.

🔗 **Play Online:** [who-is-impostor-web](https://Alijewa25.github.io/who-is-impostor-web)

## Overview

Players take turns viewing their hidden role on a single screen before passing the device. All legitimate players receive a secret word, while the randomly assigned Impostor receives no word. Players then give subtle clues to identify who is blending in without knowing the topic.

## Features

- **Single-Device Gameplay:** No backend, database, or multi-device synchronization required.
- **No Setup Needed:** Operates directly within any standard browser on mobile or desktop.
- **Multiple Word Sets:** Includes categories like Food, Cities, Everyday Objects, and Movies.
- **Tap-to-Reveal:** Ensures secret roles remain hidden between player hand-offs.

## Game Rules

1. Select the total player count (3–10) and a word category.
2. Pass the phone around to let each player privately reveal their word or Impostor role.
3. Each player gives a one-word or one-sentence clue about the target word.
4. Discuss, debate, and vote on who the Impostor is.

## Tech Stack
